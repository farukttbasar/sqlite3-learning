# SQLite Learning

Hands-on practice scripts and a modular mini-application built while learning `sqlite3` with Python.

## Repository Structure

* **`learning-area/`**: Step-by-step scripts covering basics of sqlite3
* **`small-app/`**: A simple customer manager separating database CRUD operations (`database.py`) from the terminal input flow (`app.py`).

## Quick Start

```bash
cd small-app
python app.py
